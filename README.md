# Kathakala Virtual Photobooth

**Kathakala Photobooth** adalah aplikasi *web-based virtual photobooth* yang responsif, ringan, dan siap digunakan untuk berbagai acara. Aplikasi ini mendukung sistem multi-pose, berbagai pilihan frame transparan kustom, *live preview* kamera, serta *color grading* dengan fitur Hald CLUT LUT.

---

## Fitur Utama

* **Pilihan Frame Modular**: Memungkinkan pengguna memilih dari berbagai koleksi desain frame PNG.
* **Kamera Multi-Pose**: Sesi jepret otomatis dengan *timer countdown*, efek *flash*, dan indikator pose.
* **Kamera Switch (Flip)**: Mendukung penggunaan kamera depan maupun belakang (cocok untuk akses via *smartphone*).
* **Preset Filter & Hald CLUT LUT**:
  * **Standar**: Normal, B&W Noir, Vintage, Bright, Y2K Vivid.
  * **Skin Smoothing**: Beauty Glow, Radiant Pink.
  * **Film Simulation (LUT)**: Fujifilm Astia (menggunakan pemrosesan Hald CLUT PNG 512x512).
* **Integrasi Google Drive**: Hasil foto yang di-generate otomatis terunggah ke folder penyimpanan cloud acara via Google Apps Script.
* **Proses Rendering Lokal**: Semua proses manipulasi gambar dilakukan di sisi klien menggunakan HTML5 Canvas tanpa membebani server.
